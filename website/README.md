# GraphSync website

Product landing page and documentation for the GraphSync coordination API.

- **Author & maintainer:** [Hardik Kanajariya](https://hardikkanajariya.in)

## Local development

```bash
pnpm install
pnpm dev
```

## Deploy to Vercel

1. Import this repository in Vercel
2. Set the root directory to `website`
3. Deploy

Vercel will use `website/vercel.json` for SPA routing. Production URL can serve as the public home for the API product and docs.
